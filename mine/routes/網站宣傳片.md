# 路線：網站宣傳片（用網站自己的 hairline 圖演出）

範例：`films/site-promo/`（2026-10-11，27 秒，直式 1080×1920，無旁白、簡體字卡，給小紅書／抖音／X）。

## 做法
- **畫面就是網站本身的代碼**：把網站的 `kernel.js` 和圖檔（frame、carousel）原封不動複製進片子，在頁面裡掛上去，用「看不見的手」發指標事件操作它們（指層、按下、拖轉盤）。觀眾看到的動作和網站上一模一樣。
- **虛擬時鐘**：hairline 靠 requestAnimationFrame、performance.now、setTimeout、IntersectionObserver 走。**不要改全域的 requestAnimationFrame**（渲染工具 waitForFunction 靠它輪詢，改了 READY 永遠等不到）。改成用 `new Function('requestAnimationFrame', …, 原始碼)` 把假的時鐘「傳進」引擎與圖檔的函式範圍（`CLOCK.run`）。
- **確定性**：`render(t)` 若 t 比上一次小就整個重建（destroy、重新 mount、時鐘歸零），再以 1/60 秒一步模擬到 t。video.mjs 每個 worker 渲染連續一段，所以每段只重建一次。
- 引擎的 CSS 有 `transition: stroke 260ms`（真實時間）：片子裡一律 `transition: none`。
- 線條粗細：`--hairline-stroke` 設 2.3（non-scaling-stroke，螢幕像素），手機上才看得清。
- 錨點：先掃一遍圖（每 6 單位發一次 pointermove 讀讀數），記下每個名字的位置，手的劇本寫名字不寫座標。
- 幕上的影片：雲端瀏覽器播不了 H.264，從網站的網頁版影片截 24 fps JPEG 序列（`frames.sh`），render(t) 依時間換 `<img>`。
- 光束：沿用網站的三層光錐（halo、body、core）＋灰塵，改成從下往上斜照；漸層的 stop 要自己給 `stop-color`（網站靠 CSS 變數，複製時忘了＝黑色＝看不見）。
- 鏡頭：world div 的 translate＋scale；縮放用對數插值；第一段（從游標拉出）用 ease-out 才有「一開始衝、最後停穩」的感覺；飛行段鏡頭跟著那一幀走。
- 首尾呼應：開場是 frame 圖的游標藍點，結尾光束收回成轉盤上的藍點，配同一個鐘琴音。

## 做對的事
- 主體只有一個（那一幀），轉折是「房間暗下、光束點亮」：一般觀眾不用懂代碼也看得懂。
- 五層的名字排成一行、逐個點亮（整行停 5.4 秒），比每層換一張字卡好讀，也通過 readcheck。
- 配樂用顫音琴、鐘琴、馬林巴、豎琴、水杯琴：透明的玻璃與金屬音色對應網站的通透感；拖轉盤那一下用豎琴加速上行。

## 踩過的坑
- 覆寫全域 rAF → READY 等不到（見上）。
- 光束漸層沒有 stop-color → 光束完全看不見，只剩灰塵。
- 淺色→深色的過渡拉太長（1.2 秒）會有一段灰濛濛的畫面；縮到 0.7 秒，並讓發光的那一幀一直留在畫面裡。
- 結尾標題和縮小的幕重疊：標題要晚於鏡頭拉遠（23.0 s）才出現，鏡頭終點讓幕頂落在標題下方。
