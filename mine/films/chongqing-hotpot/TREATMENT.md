# 重慶火鍋 · TREATMENT（飲食擬人系列 第 1 集）

22 秒、1080×1920、30 fps、無縫循環。2026-10-12～13 製作。
畫面由 **MiniMax 圖生視頻**生成（用戶在 MiniMax Design App 手動生成），首幀圖由 ChatGPT 圖像生成；**剪接、轉場、配樂、音效、混音、封面字全部由代碼完成**。

## 來源與取捨
- 參考片：一支韓式烤五花肉擬人短片（約 21 秒，拆解紀錄在專案 006）。借：冷 → 熱 → 變形 → 組裝的結構、每 1–2 秒一鏡、寫實食材＋擬人表演、冷藍開場對比。不借：烤肉題材、生菜包飯的結尾。
- 代碼評估：參考片的肉質、軟體物理代碼只能做 2–3 成，所以畫面交給 AI 視頻，代碼做後期。
- 三種結構候選：
  1. **一鍋食材的一生**：冷凍 → 下鍋 → 涮 → 沾碟 → 合照（✅ 選這個，能串起最多種食材，結尾自然回到冷凍庫做循環）
  2. 一卷肥牛的冒險：單一主角，但其他食材只能當背景
  3. 食材選秀：每種食材輪流表演，沒有主線
- 標竿：參考片的「每種食材都是活的」。

## ★ 風格定錠（不得跑偏）
- 畫面裡**每一種食材都是活的角色**，沒有純道具食材；有情緒、有動作、彼此互動。
- 外形：活動眼（白眼球＋黑瞳孔）＋簡單小嘴（**不要人類牙齒、不要嘴唇**）＋小手小腳（用該食材本身質地）。
- 質感：食材紋理完全寫實、看了會餓；不要漫畫發抖線等符號。
- 一個大圓鐵鍋，不要九宮格；構圖拉遠，鍋露出約 90%。
- 光：冷凍庫冷藍；其餘暖鎢絲燈＋紅油光澤，重慶火鍋館背景（木窗花、燈籠）。
- 自檢一問：「放進參考片裡，會不會格格不入？」

## 製作流程
1. 一鏡一鏡：Claude 出首幀圖（`prompts/first_frames.md`）→ 用戶在 MiniMax 生成（`prompts/minimax_prompts.md`）→ Claude 逐幀檢查（拼圖＋每半秒畫面變化量）→ 決定剪接點 → 下一鏡。
2. `cut.py`：裁切、變速對拍、調色、0.3 秒溶接（冷→熱閃白）、循環段。
3. `audio.py`：配樂與合成音效全代碼；真實底噪用 Freesound CC0。渲染兩輪取第二輪，尾音繞回開頭。
4. 母帶：壓縮 → loudnorm 兩遍 → 限幅（−14.2 LUFS、峰值 −2.5 dBFS）。
5. 封面：AI 畫空白招牌＋角色互動，`cover/plaque.py` 用宋體寫金箔浮雕字。

## 用戶回饋（照做）
- 「看了會餓」不是「純美食廣告」：一開始只讓肥牛有眼睛、其他食材寫實，偏離參考片 → 重訂風格定錠。
- 角色選方案 C（眼睛＋嘴＋手腳）；不要人類牙齒。
- 不要九宮格，一個大鍋；首幀要拉遠，鍋露出 90% 以上。
- 一鏡一鏡來，不要一次生 8 張圖。
- 按拍子剪、加循環結尾（參考 Staircase Loop Prompt Pack 的 BEATS 與 loop by construction）。
- v1 → v2：冰箱聲太大（降約 10 dB）；切得太硬 → 改溶接。入水／落油也保留溶接。
- 封面第一版「字體和排版太醜」→ 要求食材和文字互動、提升審美。

## 做對的事
- 每鏡交出提示詞前先自檢（見路線文件的清單）；發現「眨眼」會讓沒眼皮的眼睛長出眼皮，先改再交。
- 第 2 鏡固定鏡頭，整段加速成縮時，救回「融化太慢」。
- 用逐幀畫面找撞擊瞬間（入水 8.03、落油 16.4），再把第 9 鏡入點挪 0.1 秒對齊拍點。
- 第 10 鏡讓 MiniMax 自己把畫面蒸成全白，直接當循環轉場。
- 封面：圖像模型寫不準中文 → AI 只畫空白招牌，字用代碼寫。

## 踩過的坑
- 純黑豆眼要「左右看」→ 模型自己加眼白；後來乾脆用活動眼。
- 首幀第一次畫出寫實人眼，很驚悚 → 改黑豆眼 → 最後方案 C。
- 毛肚被畫成海參（圓柱、長刺）→ 出圖後要核對食材外形。
- MiniMax 後半段常出事：角色融合、湯色變混、多出一個角色 → 多數鏡頭只用前 3 秒。
- 濺起的紅油／香油皇冠常是亮橘色、偏卡通（只出現一瞬，可接受）。
- Freesound 第二天對雲端和本機都 403 限流 → 卡通音效改代碼合成。
- 這個環境不能建 GitHub Release → 素材推到 `assets/chongqing-hotpot` 分支。
- 送進對話的檔案上限 30 MB → 成片用 8 Mbps 編碼（約 20 MB）。
