# TREATMENT：小麻雀追袋記（暫名）

- 規格：1080×1920（9:16），24 fps，約 33 秒；無旁白、無字幕，只有手寫中文擬聲字；−14 LUFS。
- 畫面：ChatGPT 生成的寫實台灣日常物件照片，加代碼手繪的鋼筆淡彩塗鴉。塗鴉的筆觸文法參考 opuscar `urban-sketch`：細墨線會抖、會超出頭、偶爾斷筆；淡彩錯位溢出；角色 12 fps boil；逐筆畫出。
- 配樂：用戶以 Gemini 生成（提示詞依下方 cue map 撰寫）。

## 1. 三種候選結構
- **A. 一日行程**：清晨早餐店 → 夜市 → 睡覺。最自然，但和參考片「貓的一天」結構相同，放棄。
- **B. 追一個被風吹走的紅白塑膠袋**：麻雀的袋子在開場被風吹走，牠一路追，穿過每個物件，最後袋子鼓成熱氣球把牠載上天。一個主角、一個目標、一個轉折，物件之間的轉場由「飛走的袋子」帶過去。
- **C. 夜市集點卡**：每個物件蓋一個章，集滿得獎。結構像清單，故事弱。
- **選 B。** 有目標、有追逐，物件不再只是一張張並列，而是一條路線。袋子既是動機，也是結尾的變身。

## 2. Logline 與起承轉合
一隻小麻雀的紅白塑膠袋被風吹走，牠穿過早餐店、街頭、雨天和夜市一路追，最後袋子鼓成熱氣球，載牠飛上夜空。
- **起**：早餐鐵盤上吃早餐；一陣風把袋子吹走（鉤子在 3 秒內）。
- **承**：電鍋 → 蒸籠 → 珍奶 → 蚊香 → 塑膠凳，越追越快。
- **轉**：下雨，藍白拖小船慢下來（喘息）；電扇安靜一拍後吹起大風；夜市彈珠台快打。
- **合**：安靜一拍；袋子落地鼓起，變成熱氣球載起麻雀；拉遠成整頁「台灣生活圖鑑」。

## 3. 標竿
- **參考片 A（Kevin Ngo 的照片塗鴉）**
  - 學：塗鴉和真實物件互動；每個物件找一個變身點子；擬聲字只用一兩個字。
  - 不學：一天的結構；貓角色；固定鏡頭；總表結尾；任何具體物件與畫面。
- **《紅氣球》（1956）**
  - 學：讓一個物件領著主角穿越城市。
  - 不學：任何畫面與情節。
- **urban-sketch STYLE.md**
  - 學：線先於色；看不見的力要畫出來（風是會擦掉尾巴的墨線捲）；色彩從一點綻開。

## 4. 視覺系統
- **整片是一張長長的直式「頁面」**，物件照片沿著 S 形路線擺在頁面上，相機在頁面上移動。不用硬切：換場就是相機跟著袋子走到下一個物件。這是和參考片最大的差別。
- **背景**：不分場換色。頁面是暖米白冷壓紙，每個物件周圍各暈一團淡彩（早餐店暖黃 → 街頭淡綠 → 雨天灰藍 → 夜市深紫）。相機移動時，色彩自然過渡。
- **墨線**：深褐黑色，寬 2.5–4 px（以 1080 寬為準）。
- **麻雀**：圓胖、短尾、褐色淡彩，白肚，一點點腮紅。只用 4–5 筆就能畫出。
- **紅白塑膠袋（塗鴉版）**：紅白條紋的淡彩，兩個提耳。結尾由塗鴉「轉成」真實照片（招牌時刻之一）。
- **擬聲字**：手寫楷體（霞鶩文楷 TC，OFL 授權），一筆一筆出現，帶墨線抖動。

|---|---|---|---|

| 電扇、彈珠台 | 夜市人聲（J-cut 從電扇段末進來） | 嗡～、叮叮叮！ | 最滿 |

- 聲音轉場：雨聲提前在撲通前半拍進場；夜市人聲在電扇段尾提前進場；風聲從鐵盤延續到電鍋。
- 素材：音效用 numpy 自己合成，`core/audio/sfx.py` 輔助；混音後用 `mux.sh` 做到 −14 LUFS。

## 8. 文字設計
- 只有擬聲字：噗～、咚咚、啵！、咻～、撲通！、嘩～、嗡～、叮叮叮！、呼～。逐筆寫出，約 0.3 秒寫完，停留 ≥ 字數÷4.5＋1.5 秒（2 字約 1.9 秒）。快段（彈珠台）的「叮」跟著動作移動。
- 結尾標題「台灣生活圖鑑」：手寫，停留 ≥ 4 秒（6 字需約 2.8 秒，取 4 秒）。
- 位置：畫面高 15%–80% 之間，不壓住物件和麻雀。
