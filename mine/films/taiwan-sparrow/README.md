# 小麻雀追袋記（taiwan-sparrow）

33 秒、1080×1920、24 fps。路線：`../../routes/照片塗鴉片.md`。成片、照片、配樂在 [GitHub Release taiwan-sparrow-v1](https://github.com/gandongdexingfu/lemo-opuscar/releases/tag/taiwan-sparrow-v1)。

| 檔案 | 用途 |
|---|---|
| TREATMENT.md | 導演計畫（三種結構、分鏡、cue map、聲音設計） |
| index.html / doodle.js / chars.js / film.js | 畫面（canvas 2D）：塗鴉引擎、角色、全片時間軸 |
| score.py | 配樂樂譜（sampler，CC0 樂器取樣） |
| mix.py | 音效合成＋混音 |
| build.sh | 一鍵重建（先把 Release 裡的 img.zip 解到 img/） |
| prompts/image_prompts.md | 生圖提示詞與前處理 |
| fonts/wenkai.ttf | 霞鶩文楷 TC 子集（OFL） |
